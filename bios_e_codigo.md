## 2. Código Secreto — Porta para o Omaha

O Omaha (PLO) está atualmente em desenvolvimento e **bloqueado para o público**. No entanto, você tem acesso exclusivo para testar e evoluir a modalidade.

### Como destravar o Omaha:

1. Abra o app **calloufold.com.br**
2. No topo da tela, você verá dois botões: **"Texas"** e **"Omaha 🔒"**
3. Clique no botão **"Omaha 🔒"**
4. Um campo aparecerá pedindo um código
5. Digite exatamente:

```text
omaha2026
```

6. Aperte **Enter** ou **OK**

### O que acontece depois:

- O cadeado 🔒 desaparece do botão
- O botão "Omaha" fica ativo (cor branca/não opaco)
- A mesa muda para 4 cartas (grid 2x2)
- Os bots jogam ranges de Omaha
- O feedback pós-flop usa equity de Omaha
- O acesso fica salvo no seu navegador (você só precisa fazer isso uma vez)

### Como bloquear novamente (se quiser):

Para re-bloquear o Omaha e voltar ao estado público:
1. Abra o console do navegador (F12 no desktop, ou use uma ferramenta de inspeção no mobile)
2. Digite: `localStorage.removeItem("omaha_dev_unlock")`
3. Recarregue a página (F5)

Ou simplesmente limpe o cache do navegador.
