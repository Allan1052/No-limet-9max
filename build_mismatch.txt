PROBLEMA: O JS compilado no servidor ainda tem a regex antiga:
```
.match(/^(\/[^/]+\/)/)
```

Sem o fix que adiciona:
```
if (base.startsWith('/assets/')) return '/';
```

Isso significa que o GitHub Actions fez o build ANTES do meu push das correções, ou o workflow não pegou as últimas mudanças.

O script src é "/assets/index-D-qglRJh.js". A regex /^(\/[^/]+\/)/ captura "/assets/" como base path.
Então brand-logo-splash.png fica "/assets/brand-logo-splash.png" que dá 404.

SOLUÇÃO: O dist/ que foi commitado pode ter sido gerado ANTES das correções. Preciso verificar se o workflow do GitHub Actions está usando o dist/ commitado ou fazendo build próprio.
